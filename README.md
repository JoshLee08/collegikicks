# Kyorugi Weekly Planner

An interactive Olympic-style Taekwondo sparring plan built around Tuesday and Thursday evening practices and Saturday morning practice.

- Set a tournament date to see the countdown and adjust training near competition.
- Choose a course load and sparring intensity for each week.
- Select a day to see its workout. Settings are saved in the current browser.

Open `index.html` in a browser to run the planner locally. The site uses plain HTML, CSS, and JavaScript and requires no installation.
