# Kyorugi Weekly Planner

A personal Olympic-style sparring planner for UC Berkeley Taekwondo. Tuesday and Thursday evening practices and Saturday morning practice are coach-led.

- Log how hard each practice felt. A hard Tuesday makes Wednesday’s ride easy, and a hard Saturday shortens the next Monday’s lift.
- Set a tournament date and mark weeks with heavy coursework to adjust solo training.
- Select a day for workout details. Settings and practice logs are saved in the current browser.

Open `index.html` in a browser to run the planner locally. It uses HTML, CSS, and JavaScript and requires no installation.
